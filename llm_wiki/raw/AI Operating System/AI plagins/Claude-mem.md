## 2. Архитектурная роль Claude-Mem

Claude-Mem отвечает за историю работы агентов:

- что исследовали;
    
- какие изменения выполнили;
    
- какие тесты провели;
    
- какие проблемы обнаружили;
    
- на чём остановились.
    

Claude-Mem НЕ является каноническим хранилищем архитектуры проекта.

Разделение ответственности:

|Система|Ответственность|
|---|---|
|`llm_wiki/`|Архитектура и знания проекта|
|`.adr/`|Принятые архитектурные решения|
|Graphify|Поиск структурных связей|
|Source|Фактическая реализация|
|Claude-Mem|История работы и восстановление контекста|

Если память Claude-Mem противоречит актуальным ADR, Wiki или исходному коду, необходимо выявить расхождение, а не автоматически принимать историческую запись за истину.

## 3. Проверка текущего состояния

Сначала проверить, что Claude-Mem действительно работает.

В PowerShell:

```powershell
Get-NetTCPConnection -LocalPort 37777 -State Listen -ErrorAction SilentlyContinue
```

Затем открыть в браузере:

```text
http://localhost:37777
```

Проверить доступность viewer и наличие последних наблюдений.

Если порт не отвечает, не следует сразу переустанавливать Claude-Mem. Сначала необходимо проверить текущую установку, конфигурацию Claude Code и состояние worker.

## 4. Как обновлять память

Обновление должно происходить через штатный механизм Claude-Mem в Claude Code.

Порядок:

1. Открыть Claude Code в корне проекта `D:\JS_Projects\3dsonet`.
    
2. Убедиться, что интеграция Claude-Mem активна.
    
3. Передать Claude Code актуальный transfer context из основного ChatGPT-чата.
    
4. Попросить Claude сопоставить transfer context с текущими Wiki, ADR и source.
    
5. Сформировать краткое резюме новых фактов и изменений.
    
6. Сохранить результат через штатный механизм Claude-Mem.
    
7. Проверить в viewer, что новые наблюдения действительно появились.
    
8. Открыть новую сессию Claude Code и проверить восстановление этих сведений.
    

**Не считать обновление успешным только потому, что Claude ответил «запомнил».** Необходимо подтвердить запись и последующее восстановление.

Не редактировать внутреннюю базу Claude-Mem напрямую и не заменять её вручную файлом transfer context.

## 7. Важное ограничение

Claude-Mem — память Claude Code, а не общая память всех моделей.

ChatGPT не получает автоматически доступ ко всем наблюдениям Claude-Mem. Для переноса контекста между ChatGPT и Claude Code используются Wiki, ADR, transfer context и доступные интеграции.

### 4. Какую команду использовать для ручной записи?

В официальной документации Claude-Mem описан прежде всего автоматический механизм сохранения через hooks. Универсальную команду `/mem`, которая гарантированно создаёт новое наблюдение, я не подтвердил. Поэтому мой предыдущий совет использовать `/mem` для записи был некорректным.

Если требуется гарантированно сохранить конкретное архитектурное решение, его следует также зафиксировать в соответствующем ADR или LLM Wiki. Claude-Mem затем может сохранить историю работы с этим решением, но не заменяет каноническую проектную документацию.
