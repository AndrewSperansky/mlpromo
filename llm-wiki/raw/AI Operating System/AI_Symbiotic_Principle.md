
# Симбиотический принцип ИИ

Сейчас большинство людей делают

```
Проект

↓

ИИ помогает писать код
```

Мы же строим противоположную систему.

```
AI Workspace

↓

внутри него живет проект
```

Это принципиально другой подход.

И, как мне кажется, именно он позволит со временем получить действительно "память" для агентов, а не просто набор Markdown-файлов.
