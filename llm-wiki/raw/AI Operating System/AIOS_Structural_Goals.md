
## 🗺 Целевая структура [[AIOS]] (план)


AI Operating System
│
├── Source Layer
│   ├── GitHub
│   ├── Kanban
│   ├── Graphify
│   ├── Claude-Mem
│   └── [[LLM Wiki]] 
│
├── Knowledge Layer
│   ├── Architecture
│   ├── Domain
│   ├── Ontology
│   ├── [[AIOS]] 
│   ├── Skills
│   ├── Prompt Library
│   ├── Standards
│   └── Research
│
├── Context Layer
│   ├── Context Engine
│   ├── Context Bundle
│   ├── Working Set
│   ├── Session Memory
│   ├── Focus
│   └── Knowledge Packages
│
├── Operational Layer
│   ├── Sprint
│   ├── Kanban
│   ├── Roadmap
│   ├── Tasks
│   └── Project State
│
├── History Layer
│   ├── [[ADR]]
│   ├── Archive
│   ├── Changelog
│   └── Release Notes
│
├── AI Layer
│   ├── Agent Profiles
│   ├── Skills
│   ├── Prompts
│   ├── Memory Policies
│   ├── Token Budgets
│   └── Tool Permissions
│
└── Orchestration Layer
    ├── Task Router
    ├── Context Builder
    ├── Agent Selector
    ├── Memory Sync
    └── Workflow Engine


На мой взгляд, именно такая модель будет масштабироваться лучше всего. Она не привязана к конкретным инструментам: Obsidian, Graphify, Claude-Mem, Kanban или GitHub становятся сменяемыми источниками данных, тогда как AI Operating System остается стабильным архитектурным ядром проекта.
